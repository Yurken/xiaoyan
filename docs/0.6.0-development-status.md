# 0.6.0 开发状态与缺口

本文用于跟踪 [`PRD-0.6.0-桌面悬浮助手.md`](./PRD-0.6.0-桌面悬浮助手.md) 的实际落地状态。

- 开发分支：`feat/research-module`
- 当前版本：`0.6.0-dev.1`
- 最近盘点：2026-07-30
- 状态定义：`已实现` 表示主路径已有代码和自动化验证；`部分实现` 表示可运行但尚未满足完整验收标准；`未实现` 表示只有规划、数据结构或占位代码。

## 已实现的基础能力

- `已实现` 独立 `assistant-dock` 和 `assistant-panel` Tauri 窗口，以及受限 capability。
- `已实现` macOS 悬浮球、系统托盘和全局快捷键入口。
- `已实现` 辅助功能权限、屏幕录制权限检查与系统设置入口。
- `已实现` 选中文本、剪贴板、手动粘贴和交互式区域截图四种输入路径。
- `已实现` 发送前预览、内容编辑、取消、重试和隐私阻断提示。
- `已实现` 解读、翻译、临时多轮上下文问答，以及文本/图片模型路由。
- `已实现` 结果复制、知识笔记导入和截图资产导入。
- `已实现` 默认禁止应用、敏感窗口标题和凭据模式检查。
- `已实现` macOS 平台适配器与 Windows/Linux 不支持适配器边界。

### F3. 解读、翻译与对话 — 已实现

已完成真实模型调用、文本/视觉输入、可取消的事件流、临时多轮会话、基础错误反馈和结果复制。停止生成后保留已接收内容；完成结果展示实际解析到的模型名、耗时，以及明确标记为“约”的本地输入/输出 Token 估算。全局用量统计仍优先采用服务商返回的真实 usage。

完成情况：

- [x] 改为流式输出，支持停止并保留已输出内容；关闭助手总开关时同步中止仍在运行的助手任务。
- [x] 展示 Token、模型名称和调用耗时；结果卡明确区分本地估算 Token，避免与服务商计费用量混淆。
- [x] 解读模式切换：默认学术，可选通俗、图表、代码/报错；模式参数由前端显式传递，后端校验并路由到独立提示模板。
- [x] 翻译目标语言与术语呈现偏好持久化并跨窗口同步；后端白名单校验后注入翻译模板，结果卡支持用户显式执行原文/译文双语复制。
- [x] 用户显式开启后，以所选研究主题为边界纯本地检索论文片段、知识笔记与内部 Wiki；不额外调用 embedding 服务，结果卡仅在实际命中时展示主题和结构化引用来源，未开启或未命中时不暗示使用知识库。
- [x] 临时多轮 `AssistantSession` 在助手窗口内存中保存消息，后续追问复用已确认上下文而不重新读取第三方应用；关闭或切换来源即清除。用户显式保存后，主题、来源、文本/截图上下文和消息会原子复制到既有正式聊天体系，并可在主窗口直接接续。
- [x] 结果页明确展示后续追问仍会使用的捕获内容与本地知识，支持逐项移除；移除后前端不再向后续命令携带原捕获内容或开启本地检索，转正式会话时也不会复制已移除的捕获内容，已有回答与既有引用仍保留。
- [x] 翻译结果卡允许用户录入原术语和选定译法，按目标语言保存、覆盖或删除稳定术语偏好；后续翻译仅将当前原文实际命中的映射注入模型，截图场景使用该目标语言下的有限词表，且将映射明确标记为词汇数据而非指令。
- [x] 结果复用共享 `MarkdownRenderer` 展示标题、列表、代码块、GFM 和公式；流式未闭合 Markdown 也随增量安全重渲染，纯文本结果保留换行。

### F4. 导入与来源追溯 — 部分实现

已完成知识笔记和本地图片写入，并在主窗口开放统一收集箱处理稍后内容、论文与文件候选。

仍需完成：

- [x] 导入前明确确认来源、研究主题、目的地、是否保留原始内容、保留策略、本地存储位置和预计空间；知识笔记写入主题关联，稍后处理按条目保存到期策略，图片资产始终保留经校验的原始截图。后端对主题存在性、目标与保留策略组合进行二次校验，并在持久导入记录中保存实际选择与存储元数据。
- [x] 主窗口新增“收集箱”，集中展示稍后处理项、论文候选和已确认的 Markdown/TXT/图片候选；稍后内容可转为保留来源的知识笔记，PDF 复用既有论文复制、解析、分块和元数据识别管线，普通文件按真实目标转换。处理过程使用可恢复状态，失败会退回待处理，移除候选不会删除用户原文件。
- [x] 导入时将来源类型、应用、窗口和捕获时间复制到持久导入记录，避免临时会话过期后失去来源。
- [ ] 截图已记录可验证的像素宽高并随导入来源持久化；知识笔记阅读页已可展示、编辑来源标题、链接、应用、窗口、捕获时间和原始截图附件。收集箱已开放独立图片资产区，可列出受管文件、识别文件缺失、编辑来源并经二次确认安全删除文件与追溯记录；列表不读取图片正文，也不向前端暴露绝对路径。当前仅剩系统交互式截图尚不能返回跨显示器全局 `x/y` 坐标。
- [x] 文本结果可将原始截图显式保存为受管笔记附件；删除笔记时先在受限目录内安全暂存附件，再原子删除数据库记录和来源追溯，成功后清理文件。路径异常会停止删除，且系统截图临时文件仍在读取后立即清理。
- [x] 图片导入按经文件头验证的真实 MIME 保存 `.png`、`.jpg`、`.webp` 或 `.gif`；声明类型与内容不符时拒绝写入资产。

已完成主动触发、默认预览、默认禁止列表、基础敏感模式和独立窗口 capability。

仍需完成：

- [x] 用户可管理的允许/禁止应用列表，且禁止名单优先级最高。
- [x] 邮箱、手机号、银行卡号、身份证号和一般 Key/Token 等疑似敏感片段由后端默认替换为类别占位符，只把遮盖版返回前端，并在预览中解释命中类别、要求额外一次确认；即使用户关闭常规完整预览也不能绕过。手动粘贴和编辑后的文本会在确认时重新检查，明确密码字段、私钥和 Bearer 凭据仍清空预览并直接阻止，原值不写入捕获表、日志或模型请求。

- [ ] 完整键盘焦点顺序、屏幕阅读器标签、动态字体和深浅色回归。
