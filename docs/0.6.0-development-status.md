# 0.6.0 开发状态与缺口

本文用于跟踪 [小妍桌面助手 PRD](./PRD-0.6.0-桌面悬浮助手.md) 的实际落地状态。

- 开发分支：`feat/0.6.0-assistant`
- 当前版本：`0.6.0-dev.1`
- 最近盘点：2026-09-22（本次核对面板采集确认、关闭与切换的异步边界）
- 状态定义：`已实现` 表示主路径已有代码和自动化验证；`部分实现` 表示可运行但尚未满足完整验收标准；`未实现` 表示只有规划、数据结构或占位代码。

## 已实现的基础能力

- `已实现` 独立 `assistant-dock` 和 `assistant-panel` Tauri 窗口，以及受限 capability。
- `已实现` macOS 桌面小妍形象、系统托盘和全局快捷键入口。
- `已实现` 辅助功能权限、屏幕录制权限检查与系统设置入口。
- `已实现` 选中文本、剪贴板、手动粘贴和交互式区域截图四种输入路径。
- `已实现` 发送前预览、内容编辑、取消、重试和隐私阻断提示。
- `已实现` 解读、翻译、临时多轮上下文问答，以及文本/图片模型路由。
- `已实现` 结果复制、知识笔记导入和截图资产导入。
- `已实现` 默认禁止应用、敏感窗口标题和凭据模式检查。
- `已实现` 可选直达动作快捷键：直接解读选区（Alt+1）、直接翻译选区（Alt+2）、框选截图（Alt+3），默认不注册，设置页可开启/录制/冲突重试；保存与重试按全局串行执行，进行中会锁定所有动作行，避免并发响应覆盖状态；触发仍走现有采集降级、敏感检查与预览策略。
- `已实现` 截图识字（提取文字）：复用视觉模型路由转录截图文本，结果进入可编辑预览并固定标注“识别可能有误”，确认后可继续解读/翻译/对话；指标 action 白名单已扩展。
- `已实现` 面板自由输入：无采集上下文时可直接输入问题开启临时对话，空上下文会话不带捕获内容，可追问、保存为正式会话。
- `已实现` macOS 平台适配器与 Windows/Linux 不支持适配器边界。

## 2026-09-22 面板确认与取消体验收口

- 采集确认绑定内容版本和会话：确认期间修改文本会撤销旧确认，需按新内容重新检查；切换来源、取消、清空或卸载后，旧回执及错误不再改变当前预览。确认按钮显示进行中状态并阻止重复提交，编辑和取消仍可用。
- 选区降级到剪贴板或手动粘贴时逐步核对是否仍有效；取消后不再读取下一来源。选区读取失败且剪贴板为空时，只读取一次剪贴板。
- 截图识字和自由提问的准备请求支持重置：关闭面板、清除助手数据或新采集开始后，迟到结果不再覆盖预览或启动旧问题的模型调用；无效的自由提问临时会话会丢弃。已发出的非流式 OCR 请求没有新增后端中止协议，本轮隔离其前端回执，不宣称已停止服务商处理。
- 采集确认、来源请求、快捷键事件和面板动作编排拆为独立 hook；面板窗口保留组合职责。快捷键监听保持稳定，避免普通重渲染时注销/注册造成触发间隙。
- 回归采用合成输入、受控 Promise 和模拟 Tauri 命令，覆盖旧确认污染、新内容重新确认、关闭与清除数据后的自由提问、识字期间切换来源，以及旧请求不干扰新请求状态。没有使用真实研究正文或外部模型调用，也不涉及模型升级采纳。

本轮自动化不替代多显示器、权限授予/拒绝、VoiceOver 和真实 macOS 关闭行为验收；发布矩阵仍保留待测。
