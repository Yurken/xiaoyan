# 2026-10-04 · Desktop 基础功能评估与可靠性修复

## 结论与范围

小妍的主要基础功能已有真实前后端实现；本轮没有发现主要页面按钮仅返回演示占位结果。但“有实现”不等于“任意环境下都能完成”：AI 依赖有效模型配置，检索与同步依赖外部服务，LaTeX PDF 编译依赖系统 TeX，桌面采集依赖 macOS 权限与应用兼容性。完整数据迁移、扫描 PDF、复杂 TeX 工程导入等仍有明确缺口。

评估以 Desktop 为旗舰端，覆盖本地资产、研究工作流、AI 与代码、桌面助手、设置和迁移。Web/Mobile 不按 Desktop 功能对等验收。开始基线为 `e6062eda`，版本 `0.6.0-dev.1`，分支 `codex/desktop-session-reliability`。本轮是产品可靠性评估，不是 Codex 或小妍模型升级，也不作为发布日志。

采用三种证据等级：

- **实现与自动回归**：前端调用、Rust 命令、数据库/文件路径和对应自动测试可核对。
- **依赖条件**：真实实现存在，但完整任务依赖模型、网络、TeX、原生系统等条件；单元测试和浏览器夹具不能代替这些条件的验收。
- **部分实现**：已有基本流程，但某些常见输入、规模或恢复场景尚未覆盖。

## 本轮采用的修复

按域拆成独立的失败复现与修复切片，各切片保留受控 Promise、错误注入和生命周期回归；没有用通过所有既有测试代替缺陷复现。

1. **设置保存**：加载失败禁止保存默认值；应用版本元数据失败不阻断设置读取；同窗口自动保存串行、确认最新表单后才显示成功；错误持续并可重试；收到导入/历史正式快照时重新排队，避免旧回执覆盖；离页与重新挂载共享写入协调。真实导入命令与随后读取尚未整体排队，多窗口也未协调，不能据此宣称所有配置修改入口均无竞争。
2. **阅读持久化**：每篇论文拥有独立的记录、反馈和撤销历史，持久化尾队列在同一窗口内跨挂载保持顺序；返回论文时等待旧操作完成，全部语料与单论文操作也协调重叠范围；失败不消耗撤销项、不删除已保存数据；恢复批注后重映射 ID；摘录等待真实成功、避免重复点击，切换与卸载清理反馈。
3. **写作保存与恢复**：SQLite 写成功后才确认签名和时间；失败创建继续以创建重试；跨挂载加载与写入按顺序执行；离页补保存，在本机 localStorage 可用时记录未确认文稿，重新进入后恢复，数据库内容分叉时创建恢复副本并展示恢复提示。
4. **代码工作区**：请求 ID 在首个事件之前确定；停止、切换、删除及卸载取消当前请求；事件同时匹配请求与会话；迟到回执不污染新任务；目录读取与根目录选择分离；显式模型选择进入原生请求。
5. **投稿预审**：关闭后结束当前 UI 生命周期，重开生成新请求范围；旧错误、完成及 PDF 读取结果不写入新弹窗。
6. **备份保护与范围**：显式展示范围和排除项；新增独立 Rust 导入保护，在同一恢复事务、清空任何表之前检查未备份表指向待清空父表的 CASCADE/SET NULL/SET DEFAULT 关系，按实际关联行计数，存在受影响资产就拒绝导入并返回数量。批注、语料和实验快照不会再因这条恢复路径被默默清除；空库与无父关联的全局语料可放行。本轮没有扩展备份格式与白名单，也没有解决文件恢复的原子性、多窗口协调或全部迁移覆盖。

触达的大逻辑已先拆到 domain hook：设置持久化、阅读会话与摘录反馈、写作持久化、代码请求与文件树。页面仅接回动作与状态，不在大页面追加异步状态机。

## 验证证据

开始时 Desktop Vitest 为 **171 文件 / 707 项通过**；Rust 为 **396 通过 / 4 项按设计忽略**。自动测试总数覆盖多个功能域，但数量不是功能完成率。

最终前端回归：**181 文件 / 802 项 Vitest 全部通过**；仓库级 `pnpm type-check`、`pnpm lint` 与 Desktop 前端构建通过，lint 0 error、25 个既有 warning。原生命令静态核对得到 388 处字面量 `invoke`、354 个不同命令名，与 373 个注册命令对比没有缺失项；动态构造命令和运行时参数仍需对应测试。

最终 Rust 全库 **404 通过 / 4 项按设计忽略 / 0 失败**。导入保护新增 6 项真实内存 SQLite 回归；旧行为在级联删除与 SET NULL 两例中失败，修复后覆盖批注/语料/快照保留、空库及全局语料放行、重复外键计数、异常元数据拒绝、带引号表名与隐式复合主键。

真实 AI 烟雾测试 `ai_live_settings_present` 与 `ai_live_chat_smoke` 均通过，后者只发送最小公开合成消息并收到“在线”，不发送研究资产、不修改模型配置。这只能确认当前配置的一条真实连接，不证明科研质量或其他提供商可用。

浏览器回归使用本机已有 Chrome，Vite/Tauri API 夹具运行，最终 **52/52 通过**。首次 51/52 通过，唯一失败来自写作测试夹具缺少 CRUD 返回；本轮补充有效内存 CRUD 夹具后重跑。它验证浏览器页面交互，不能替代原生桌面端端到端测试。

全仓 `cargo fmt -- --check` 仍有 23 个未触达文件的既有格式差异；这些文件没有本轮改动。本轮触达的 Rust 文件单独 `rustfmt --check` 通过，不把全仓格式检查登记为通过。

E01/E02/E06/E08 历史固定门禁 `paper-facts-2026-08-13` 对 `local-boundary-2026-08-13` 重跑通过，均分 2.5、硬失败 0、未知硬失败 0。它核对的是既有证据报告，不能登记为本轮新模型能力收益。
