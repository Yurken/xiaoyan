# 0.6.1 发布前检查

日期：2026-10-22。目标分支：`master`；候选分支：`codex/iteration`。

## 发布差异基线

GitHub 实际最新已发布版本为 `v0.5.4`。更新日志以 `git diff v0.5.4 <候选提交>` 和完整提交历史为依据；开发期 `0.5.5`、`0.6.0-dev.1` 未作为独立发布版本对比。还原真实 `0.5.4` 历史条目，合并未发布的开发记录。

- 新增归并为桌面助手、文件中转站、系统托盘驻留和移动端连接/通知配置；桌面助手开发阶段的改进与缺陷修复均归入首次交付说明。
- DSH、知识笔记、论文阅读、写作、设置与备份同步在 `0.5.4` 已存在，按体验改进或原有错误归类。
- 未将停用的 Codex/OpenCode/Pi、隐藏的研究工作台和内部重构作为新增发布能力。
- 版本元数据统一为 `0.6.1`，Android 原生 `versionName` 同步，`versionCode` 从 5 提升到 6；API SDK 维持其独立包版本 `0.1.4`。

## 入口与保留策略

- DSH 自动进入官方界面；旧必经启动页移至 `LegacyDshLaunchWorkspace.tsx`，仅注释原入口，保留完整源码与配置回归。
- 非 DSH 的页面、后端模块、注册与设置入口注释停用；保留源码、子模块、固定版本、已有配置和用户数据；旧路由兼容转入 DSH。
- API 同步由主 WebView 执行，避免浮窗在停止 DSH 后被销毁而丢失重启；提供确认、去重、恢复和结果回放。
- 桌面小妍默认关闭；启用后的形象右键菜单提供打开面板、粘贴文件、设置和关闭。
